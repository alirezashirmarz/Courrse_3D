# Day 03 — Your first 3D Python program (book Ch. 3)

## Run

- `python first_program.py` creates `data/street_scene.txt`, loads it, prints statistics per class, filters by height and exports `.ply` files to `outputs/`.

Outputs go to `outputs/`. Set `COURSE_NO_VIZ=1` to skip 3D windows.

## Try this

1. Change the height threshold and find the value that best separates ground from objects.
2. Export ONLY the roof (class 2) and open it in https://3dviewer.net.
3. Replace the data file with one of the book's datasets (adjust the delimiter and column indices).
